# neutral-data-collector
Автоматический сбор и балансировка текстов для обучения локальной LLM. Поиск нейтральной информации из открытых источников, фильтрация эмоций, токсичности и однобоких мнений. Оценка нейтральности через RuBERT, дедупликация, балансировка классов. На выходе — структурированный датасет для fine‑tuning и RLHF. Локально, CPU, соблюдение 152‑ФЗ.
